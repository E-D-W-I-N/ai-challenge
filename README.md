# День 04 — `temperature` 0 / 0.7 / 1.2

## Задание

```
🔥 День 4. Температура

Выполните один и тот же запрос с параметрами:
👉 temperature = 0
👉 temperature = 0.7
👉 temperature = 1.2

Сравните ответы по:
👉 точности
👉 креативности
👉 разнообразию

Сформулируйте:
👉 для каких задач лучше подходит каждая настройка

Результат:
Примеры ответов с разной температурой и выводы по их использованию
```

## Промпт

Сценарий один, промпт на все три колонки тоже один — отличается только
`temperature`. Системного сообщения в этом дне нет.

Вопрос:

> Ответь ровно двумя строками, без пояснений и без нумерации.
> Строка 1: название для кофейни на маяке — 1–3 слова, без кавычек.
> Строка 2: год выхода первого iPhone — только число, без точки.

Первая строка — задача открытая: допустимых ответов много, и на ней виден
разброс. Вторая проверяемая, **эталон — `2007`**: видно, чем платят за
разнообразие, когда вместе с фантазией разъезжается и факт. Кавычки и точку
промпт запрещает ради счётчика — уникальность считается точным совпадением
текста, и `Маяк и Зерно` с `«Маяк и Зерно»` пошли бы в него как два ответа.

Модель — `openai/gpt-4o-mini`, `max_tokens = 80`, по пять прогонов на колонку.
**Менять её в дропдауне нельзя:** все пятнадцать вызовов закреплены за
эндпоинтом `openai` через `provider.order` с `allow_fallbacks: false`, и на
чужой модели все три колонки упадут с ошибкой роутинга — правьте пару
`MODEL` + `PROVIDER` в `day.py`. Рассуждающие модели не годятся тем более:
температуру они молча игнорируют, и день покажет неправду.

## Вывод

Прогон отправляет один и тот же запрос пятнадцать раз — три колонки по пять
прогонов, — и под каждой колонкой стенд считает долю уникальных ответов. Это
и есть измеряемая величина дня: температура — свойство статистическое, у одного
ответа разброса нет. Типичная картина — `1 из 5` → `3 из 5` → `5 из 5`.

- **`t = 0.0`** — пять одинаковых блоков. Модель берёт самый вероятный токен,
  вторая строка почти наверняка `2007`. Это база, относительно которой читаются
  остальные две колонки.
- **`t = 0.7`** — названия расходятся, смысл держится: каждое можно повесить на
  вывеску, часть прогонов при этом повторяет одно и то же, факт обычно на месте.
  Рабочий режим по умолчанию у большинства чат-моделей.
- **`t = 1.2`** — хвост распределения получил шанс. Названия неожиданные и
  разнородные, попадаются вычурные и просто кривые, а вторая строка здесь
  вероятнее всего поедет: другой год, диапазон вместо года, лишние слова.

Отсюда и ответ на вопрос задания: разнообразие и ошибки растут вместе, это одна
ручка, а не две. Слева скучно, но верно — туда идут извлечение фактов, разбор
документов, код. Справа интересно, но ненадёжно — только черновики и мозговой
штурм. Посередине рабочий компромисс, поэтому `0.7` и стоит по умолчанию.

`t = 0` при этом **не значит «детерминизм»**: это лишь выбор самого вероятного
токена, а батчинг на GPU и маршрутизация по экспертам всё равно разводят
прогоны — `2 из 5` слева не поломка. `seed` не фиксируем намеренно: он схлопнул
бы правую колонку и убил ровно тот эффект, ради которого день и сделан.

Под колонками стенд разворачивает вердикт модели-судьи по четырём вопросам дня:
разнообразие, точность, креативность и вывод о применимости температур.

## Как запустить

```bash
cp .env.example .env          # впишите OPENROUTER_API_KEY
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload --port 8000
```

Откройте http://127.0.0.1:8000 и нажмите «Старт». Ждать дольше обычного:
пятнадцать вызовов за прогон.

`.env` в `.gitignore`. Репозиторий публичный: ключ, попавший в коммит, отозвать
уже нельзя — никогда не коммитьте через `git add -A`.
