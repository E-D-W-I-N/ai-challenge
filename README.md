# День 14 — инварианты: чего ассистент не вправе предлагать

```
🔥 День 14. Инварианты
Добавьте в ассистента инварианты, которые он не имеет права нарушать
(архитектура, технические решения, ограничения по стеку, бизнес-правила).
Инварианты хранятся отдельно от диалога; ассистент явно учитывает их;
отказывается предлагать решения, которые их нарушают.
```

## Вывод

| | |
|---|---|
| Два PR | слой (хранение, ручки, врезка, вкладка) и сторож, смотрящий на ответ |
| Слой отдельно от диалога | таблица `invariants` **без** `session_id`, как память и профиль |
| Виды | архитектура, техническое решение, ограничение стека, бизнес-правило — ни одно слово не занято соседним слоем |
| Модель их видит | блок `[чего нельзя]` в единственном системном сообщении: вид и текст, списком — и **ни одного запрещённого слова**: перечисленный запрет подсказывает его употребить, да и законный отказ стал бы невозможен |
| Сторож смотрит на ответ | нашёл слово — отметка в метриках обмена и своя строка под карточкой |
| Пишет в слой только человек | пути у агента нет; вид записи выбирает тоже он |

```
system: СИС

        [чего нельзя]
        1. ограничение стека: бэкенд только на Python
        Соблюдай это. Если просьба противоречит пункту — откажись и назови его.
```

## Сторож

Ищет слова из списков в **готовом** ответе — целиком собранном, до записи
в историю, теми инвариантами, что уехали в этот промпт.

* слово целиком (`Java` внутри `JavaScript` не отмечается), регистр не важен,
  кириллица и латиница одним правилом; граница — не `\b`, а «не буква и не
  цифра» по краям: иначе `C++` не найти;
* отметка — ключ `banned_hits` в метриках обмена, рядом с `dropped`: слово
  и правило. Колонки нет — метрики пишутся с репликой, значит отметка видна
  и в старых обменах; в суммы по чату ключ не идёт;
* под ответом **своя строка**, а не приписка к числам: ««Java» задело запрет —
  ограничение стека: бэкенд только на Python».

Ответ **не прячется, не режется и не переспрашивается**: он случился и оплачен.
Сжатия сторож не касается: пересказ разговора не ответ собеседнику.

## Ручки

| Ручка | Что делает |
|---|---|
| `GET/POST /api/invariants` | все; новый — `{"kind", "content", "banned"}`, слова необязательны |
| `PATCH/DELETE /api/invariants/{seq}` | правка подмножества полей; убрать один |
| прочие | `/api/profile`, `/api/memory`, `/working`, `/task`, `/messages`, `/fork`, `/api/agents`, `/api/models`, `/api/health` |
| отказы | вид обязателен и без умолчания; лишнее поле и пустое тело правки — 400, чужой номер — 404 |

## Проверки

Живых вызовов к LLM нет; `browser_check.js` исполняет настоящий `app.js` под node.
```bash
.venv/bin/python checks/run_checks.py    # 37 проверок, включая три ниже и клиентскую
.venv/bin/python checks/restart.py       # два процесса подряд на одном файле
.venv/bin/python checks/two_processes.py # сервер и консоль на одной базе
.venv/bin/python checks/spawn_100.py     # сто агентов в одном процессе
node checks/browser_check.js             # клиент под node, 350 утверждений
```

Про сторожа две (про слой — ещё две, из первого PR): слово целиком, любым регистром,
алфавитом и со знаком внутри, но **не** подстрока и не словоформа; отметка рядом
с репликой — разрезанный на символы ответ, перезапуск, суммы, сводки.

## Как запустить

```bash
cp .env.example .env    # впишите OPENROUTER_API_KEY; он в .gitignore
python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload --port 8000
```

Вкладка **«Инварианты»**: «бэкенд только на Python», вид — «ограничение стека»,
слова — «Java, Kotlin». Спросите «на чём писать бэкенд?». Без браузера —
`.venv/bin/python -m app.cli`. Репозиторий публичный: не коммитьте `git add -A`.

## Что осталось честно назвать

* **Ложные срабатывания штатны**: законный отказ содержит запрещённое слово
  («почему не Java?» → «Java здесь не подойдёт») — самый частый и неустранимый
  случай; следом цитата вопроса и слово в имени пакета. Сторож не цензор: он
  ставит отметку, судит человек; список слов необязателен.
* **Словоформы не ловятся**: «Котлином» при запрете «Котлин» пройдёт мимо —
  морфологии у нас нет, и это пробел, а не решение.
* _Живой прогон на ключе:_ **место под числа оставлено пустым — впишет человек.**
