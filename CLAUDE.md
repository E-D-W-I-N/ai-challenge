# CLAUDE.md

Чат-клиент поверх OpenRouter: FastAPI, ванильный JS без сборки. Зависимостей три —
`fastapi`, `uvicorn`, `httpx`; в клиент не тянется из сети ничего.

## Среда

Системный `python3` — это 3.9: без зависимостей это `ModuleNotFoundError: fastapi`,
с ними проходят 4 проверки из 15, остальные 11 падают (`TaskGroup`, `aclosing`,
нет текущего event loop). Везде только 3.11.

```bash
/opt/homebrew/bin/python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload --port 8000   # http://127.0.0.1:8000
```

## Безопасность

Репозиторий публичный, а в `.env` (`cp .env.example .env`, файл в `.gitignore`)
лежит `OPENROUTER_API_KEY`. Ключ, попавший в коммит, отозвать уже нельзя:
**никогда `git add -A` и `git add .`** — только точечно перечисляя файлы.
Живых вызовов к модели не делать: в проверках `stream_completion` подменяется
заглушкой (`checks/_stub.py`), ключ ей не нужен.

## Проверки

```bash
.venv/bin/python checks/run_checks.py   # 15 проверок, включая обе ниже
.venv/bin/python checks/spawn_100.py    # сто агентов в одном процессе
node checks/browser_check.js            # клиент под node, 131 утверждение
```

## Что нельзя сломать

* `provider.require_parameters` — в теле каждого вызова (`build_payload`, `app/llm.py`); `extra_body.provider` мержится поверх, флаг обязан уцелеть;
* `usage: {"include": true}` запрошен — итоговые токены и цену называет провайдер;
* незаданный параметр сэмплирования не уходит вовсе: ни как `null`, ни как ноль;
* агент — отдельная сущность (`app/agent.py`), про FastAPI и SSE не знающая: `ask()` берёт текст пользователя и сам склеивает промпт;
* реестр — словарь в памяти процесса: сто агентов это сто объектов и ноль вызовов к модели, перезапуск не переживает ничего;
* `copy_spec` копирует конфиг вглубь, и обмен идёт на слепке, снятом в начале `ask()`;
* в модель уезжает вся история (`Agent.build_prompt`) — окна памяти нет;
* история пишется только в `_commit`, по итогу обмена: ответа не случилось — не записано ничего;
* второй параллельный обмен с агентом — 409, бронь берётся до первого `await` (`Agent.reserve`);
* наружу отдаётся `has_key` и только он: самого ключа нет ни в ручках, ни в интерфейсе;
* текст ответа экранируется **до** разбора markdown, иначе ответ модели станет разметкой страницы.

## Про проверки

Бьют по поведению, а не по исходнику: таблиц запрещённых слов, проверок про
выпиленные механики и самопроверок стенда здесь нет, и заводить их не надо.
Исключение одно и названо явно — статика клиента в `check_key` и `check_client`
(`checks/run_checks.py`): девять утверждений по тексту `app.js`, `index.html`
и `style.css` — пять слов про ключ, пять шаблонов походов в сеть, теги `script`
и `link`, правила ленты и композера. Без браузера их не утвердить иначе, и они
стерегут свойство продукта, а не отсутствие слова. Всё остальное про клиент — не греп:
`browser_check.js` исполняет настоящий `app/static/app.js` под node на стенде
`checks/dom.js`.
