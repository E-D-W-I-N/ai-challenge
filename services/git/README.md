# Независимый Git MCP-сервис

Python >=3.11, установленный `git` и собственный MCP SDK. Сервис не импортирует
app/Agent/Store/LLM, не открывает базу чатов и не использует ключ модели.
Репозиторий выбирает оператор сервиса через обязательный `--repo`; URL-клиент
приложения не выбирает и не меняет его путь.

Из корня этого проекта, в отдельном терминале:

```sh
python3.11 -m venv /private/tmp/git-mcp-venv
/private/tmp/git-mcp-venv/bin/python -m pip install -r services/git/requirements.txt
/private/tmp/git-mcp-venv/bin/python -m services.git --repo /absolute/path/to/repository --port 8017
```

В «Настройки → Инструменты» приложения задайте любое имя и
`http://127.0.0.1:8017/mcp`, сохраните и подключите. Сервис продолжает работать
после disconnect/shutdown приложения; остановка сервиса — Ctrl+C в его терминале.
`--host` по умолчанию `127.0.0.1`. Для явной stdio-фикстуры добавьте `--stdio`;
тонкий старый app entry point выбирает только репозиторий своих локальных проверок.

Инструменты: `git_log(n=10)` (1–100 коммитов), `git_status()` (porcelain),
`git_diff_stat(ref="HEAD~1")` (сводка diff). Все запускают read-only Git без shell,
в заданном каталоге, с таймаутом 15 секунд. Пустой вывод сохраняется пустым,
ошибки Git не скрываются; ref не может быть опцией команды. Данные удалённых
провайдеров и модельные настройки сервису не нужны.
