# Карта CLI дня 31

| Задача | Файлы | Проверка | Архитектура |
|---|---|---|---|
| Команды, prompt, краткая история | assistant/cli.py | make check, ручной диалог | Запрос и контекст |
| Приватные настройки | assistant/settings.py | make check | Подключение, секреты и состояние |
| HTTP, reasoning, proxy | assistant/models.py, shared_models/ | make check | Подключение, секреты и состояние |
| Scan/chunks/cache/retrieval | rag/index.py | make check | Индекс |
| Git HTTP MCP и binding | services/git/, assistant/mcp.py | make check | Запрос и контекст |

Ручной маршрут: `make setup`; отдельно запустите Git MCP с `--repo` своего
проекта; запустите CLI с тем же `--project`; в `/settings` укажите URL, optional
ключ, generation model и embedding model, MCP URL. `/models` проверяется только
при сохранении настроек; генерация не запускается. Укажите свои glob excludes,
если tracked документация содержит приватные материалы. `/index` показывает
числа документов/чанков и новых/переиспользованных embeddings.

`/help Как устроен проект?` и обычный вопрос используют одинаковые источники.
Проверьте file:lines под ответом, свежую ветку/HEAD после переключения ветки,
предупреждение stale после изменения README. `/index` обновляет индекс явно.
`/status` не вызывает модели. `/new` очищает три пары памяти; перезапуск также
начинает пустую историю. При неправильном `--repo` MCP запрос должен отказать.
При ошибке соединения, формата или reasoning OFF нарушения повторный платный
вызов не производится. Качество/дословность цитат остаются ручной оценкой.
